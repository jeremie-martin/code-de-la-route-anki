# Carte des connaissances — ce qu'il faut savoir pour réussir l'ETG

Ce document inventorie, thème officiel par thème officiel, les **unités de connaissance** que l'épreuve
mobilise, et indique pour chacune le **type de carte** retenu (R = Reconnaissance, X = Confusion,
F = Fait/cloze, Q = Question, S = Scénario) et son **importance** (E = essentiel, U = utile, r = rare).
C'est la liste de contrôle qui pilote `data/`. Toute connaissance absente d'ici n'a pas de carte ;
toute carte doit se rattacher à une ligne d'ici.

Pondération de l'épreuve (40 questions, cf. `docs/01-analyse-examen.md`) : le thème **C – Le
conducteur** pèse ~10 questions ; **L – Circulation** ~4 mais irrigue toutes les autres (on ne peut
juger une photo sans connaître la signalisation et les priorités) ; U ~4-5, R ~4, M ~3-4, D ~3-4,
P ~3, S ~3, E ~3, A ~1.
