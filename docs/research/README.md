# Recherche

Documents datés, conservés comme trace : ils ne sont pas tenus à jour. Les règles actuelles se lisent dans les
sources primaires ; les consultations sont datées dans `data/_meta/source_checks.yaml`.

- `sources/` : copies des sources primaires (Code de la route consolidé au 10/09/2026 en PDF, et `cdr.txt`, son
  texte, à produire avec `pdftotext -layout` ; exemples officiels de questions 2023 ; communiqué DSR 2023).
- `verification-2026-09/` : vérification de chaque note contre sa source (23/09/2026) : consigne, registre par
  note, constats sourcés.
- `exam.md` : dossier sur l’ETG telle qu’elle se passe en septembre 2026 (format, banque, types de questions).
- `comparaison-livre-2025-2026.md` : comparaison ciblée avec un livre de code 2025–2026 (apports retenus,
  divergences).

Les premiers dossiers de recherche (`legal-facts.md`, `knowledge-facts.md`, `signs-notes.md`) et la liste des
illustrations écartées (`docs/candidats-visuels.md`) restent dans l’historique git, par exemple
`git show 69ece0b:docs/research/legal-facts.md`. Ils ne font pas foi.
